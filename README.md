# Лабораторные работы. Частые наборы и ассоциативные правила (Apriori, ECLAT)

Репозиторий содержит две работы на наборе данных о покупках в супермаркете
(`src/data/baskets.csv`, 7501 корзина, 115 товаров):

* **Задание 1 (`src/Main.kt`)** — поиск частых наборов алгоритмом **Apriori**
  с параметрами (набор данных, порог поддержки, упорядочивание результата)
  и эксперименты с порогами поддержки 1–15%;
* **Задание 2 (`src/lab2/EclatLab.kt`)** — поиск ассоциативных правил
  (антецедент → консеквент, поддержка и достоверность каждого правила)
  поверх частых наборов, найденных алгоритмом **ECLAT**; эксперименты
  с варьированием порога достоверности 70–95% при зафиксированной поддержке.

## Как запустить

В IntelliJ IDEA открыть проект (каталог `lab1`): задание 1 — запуск `src/Main.kt`,
задание 2 — запуск `src/lab2/EclatLab.kt`. Рабочая директория — корень проекта,
данные читаются из `src/data/baskets.csv`.

Параметры задаются в начале `main()`:

```kotlin
// Задание 1 (Main.kt)
val minConfidence = 0.3                                  // порог достоверности правил
val thresholds = listOf(0.01, 0.03, 0.05, 0.10, 0.15)    // пороги поддержки

// Задание 2 (EclatLab.kt)
val fixedSupport = 0.002   // зафиксированный порог поддержки
val bySupport = true       // упорядочивание правил: по убыванию поддержки / лексикографическое
val maxObjects = 7         // суммарный размер антецедент + консеквент
```

Примечание: в примере к заданию 2 предложена зафиксированная поддержка 10%,
но на baskets.csv при 10% не выживает ни одна пара товаров (см. результаты
задания 1), поэтому поддержка зафиксирована на уровне 0.2% (16 транзакций) —
минимальном уровне, при котором существуют правила с достоверностью ≥ 70%.

## Алгоритмы

**Apriori** (Han, Kamber, Pei — «Data Mining: Concepts and Techniques», разд. 6.2):

1. **L1** — подсчёт поддержки каждого товара, отбор прошедших порог;
2. **aprioriGen(L(k-1)) → C(k)** — генерация кандидатов: *join* (склейка пар наборов
   с общим префиксом длины k-2) и *prune* (отсечение кандидата, у которого есть
   нечастый (k-1)-поднабор — свойство Apriori);
3. сканирование базы и отбор кандидатов с поддержкой ≥ порога → **L(k)**;
4. повторение, пока уровень не опустеет.

**ECLAT** — тот же поиск частых наборов, но в «вертикальном» представлении:
каждому товару сопоставляется tidset — множество номеров корзин, где он встречается.
Поддержка набора равна размеру пересечения tidset'ов его товаров, поэтому база
сканируется один раз, а дальнейший поиск — это обход в глубину с пересечением
множеств и отсечением ветвей, не проходящих порог.

**Правила** строятся разбиением каждого частого набора на антецедент X и
консеквент Y: support = supp(X ∪ Y)/N, confidence = supp(X ∪ Y)/supp(X),
lift = confidence/P(Y).

Диаграммы: задание 1 — `charts.html` (снимок `img/stat.png`), задание 2 —
`charts_rules.html`.
